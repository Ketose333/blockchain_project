# blockchain_project

블록체인 기반 중고차 거래 플랫폼을 주제로 진행한 팀 프로젝트 프론트엔드 저장소입니다. 차량 목록, 상세 화면, 약관 UI, 거래 화면의 사용자 흐름을 중심으로 작업했습니다.

## Status

- 2025년 팀 프로젝트 참여 기록을 보관한 아카이브입니다.
- fork 기반 협업 이력이 포함되어 있어 전체 작업 기록은 팀 프로젝트 맥락으로 봅니다.
- 현재 지원용 대표 포트폴리오는 `ketose-portfolio`에서 관리합니다.

## 담당 범위

- React 기반 차량 리스트와 상세 화면 UI 구현
- 카드와 약관 UI를 재사용 가능한 컴포넌트로 분리
- 검색, 선택, 거래 화면 흐름 정리
- 팀 프로젝트 코드베이스에서 프론트엔드 작업 참여

## 작업 포인트

- 차량 목록, 상세 정보, 판매/거래 화면의 이동 흐름을 정리했습니다.
- 반복되는 카드 UI와 약관 영역을 컴포넌트 단위로 분리했습니다.
- 팀 코드베이스 안에서 React 화면 구현과 스타일 수정을 담당했습니다.

## 기술

- JavaScript
- CSS
- React Router
